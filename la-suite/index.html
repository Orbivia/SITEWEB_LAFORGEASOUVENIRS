Le principe

Quatre étapes, simplement

Le QR code peut être personnalisé pour reprendre le style de votre événement, de votre papeterie ou de votre décoration.

1

Créez votre capsule

Renseignez votre événement et ajoutez une vidéo d'accueil destinée à vos invités.

2

Partagez votre QR code

Téléchargez votre QR code personnalisable et placez-le sur les tables, invitations ou panneaux.

3

Les invités enregistrent

Ils peuvent importer un contenu ou se filmer, s'enregistrer et prendre une photo directement depuis leur téléphone.

4

Ils choisissent la livraison

Le souvenir peut être accessible immédiatement ou rester verrouillé jusqu'à une date choisie par l'invité.

Les souvenirs

Un message, sous la forme qui vous ressemble

Chaque invité choisit le format le plus naturel pour lui.

Vidéo

Se filmer avec compte à rebours, prévisualiser, recommencer ou importer une vidéo existante.

Audio

Enregistrer un message vocal directement depuis le navigateur ou importer un fichier audio.

Photo

Prendre une photo sur le moment ou choisir une image déjà présente dans la galerie.

Jusqu'à 3 ans après l'événement

La capsule continue de vivre après le jour J.

Les invités peuvent ajouter de nouveaux souvenirs pendant les 3 années qui suivent l'événement. Une vidéo oubliée, une photo retrouvée ou un message enregistré quelques mois plus tard peuvent encore rejoindre la capsule.

Chaque souvenir conserve sa propre date de livraison : immédiate ou programmée.
