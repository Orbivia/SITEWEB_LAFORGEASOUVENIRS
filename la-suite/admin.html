Vos souvenirs sont sauvegardés automatiquement

Une sauvegarde chaque nuit, conservée 7 jours. Les fichiers inchangés sont copiés une seule fois pour limiter le stockage. Vous pouvez aussi télécharger une archive chiffrée.

La restauration remet les éléments manquants et conserve les nouveaux souvenirs. Elle nécessite les comptes organisateurs d’origine. Les mots de passe ne sont pas exportés. Les archives sont restaurables sur ce service ; elles ne remplacent pas une sauvegarde complète du projet Supabase.
